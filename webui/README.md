# 🗄 کبیر — رابط کاربری وب

رابط کاربری رسمی نرم‌افزار کبیر: **HTML/CSS/JS خالص** (بدون فریم‌ورک، بدون وابستگی
npm)، کاملاً فارسی و راست‌به‌چپ، با ۶ صفحه — وصل به پایگاه‌داده‌ی SQLite و همان
موتور محاسبه‌ی پایتون (`kabir/core/costing.py`).

## اجرا

**حالت متصل (پیشنهادی) — از ریشه‌ی مخزن:**

```bash
python main.py           # → http://localhost:8080 (مرورگر خودکار باز می‌شود)
./run.sh                 # لینوکس / مک
run.bat                  # ویندوز
```

داده‌ها واقعی‌اند: هر تغییر (متریال، سبک، پروژه، فاکتور، تنظیمات، پشتیبان)
مستقیم در `kabir.db` ذخیره می‌شود.

**حالت نمایشی (بدون سرور):** فایل `kabir-ui-standalone.html` را در مرورگر باز
کنید — رابط با داده‌های نمونه و موتور محاسبه‌ی جاوااسکریپتی (آینه‌ی دقیق موتور
پایتون) کار می‌کند و تغییرات در `localStorage` مرورگر می‌ماند. نشانگر نوار
کناری و بنر بالای صفحه وضعیت اتصال را نشان می‌دهند و اتصال مجدد به‌صورت
خودکار هر ۲۰ ثانیه تلاش می‌شود.

## ساختار

```
webui/
├── index.html               پوسته‌ی اصلی، هر ۶ صفحه، مودال‌ها، اسپلش
├── css/styles.css           سیستم طراحی ۳٫۰: توکن‌های روشن/تاریک، RTL، واکنش‌گرا، چاپ
├── js/data.js               ابزارها، داده‌های نمونه، لایه‌ی API، همسان‌سازی مدل‌ها
├── js/engine.js             موتور محاسبه‌ی محلی (آینه‌ی costing.py) + فاکتور نمایشی
├── js/ui.js                 رندرها، ویرایشگر پروژه، فاکتور، تنظیمات، رویدادها
├── manifest.webmanifest     مانیفست PWA (نصب‌پذیری، آیکون، رنگ پوسته)
├── assets/                  favicon.svg، آیکون‌های PNG، فونت وزیرمتن
├── build_standalone.py      ساخت kabir-ui-standalone.html (CSS/JS/فونت درون‌خطی)
└── kabir-ui-standalone.html نسخه‌ی تک‌فایلی
```

## API (سمت سرور: `kabir/web/server.py` — فقط کتابخانه‌ی استاندارد پایتون)

| گروه | مسیرها |
| --- | --- |
| سلامت | `GET /api/health` (وضعیت سرویس، نسخه، زمان کارکرد) |
| اولیه | `GET /api/bootstrap` (همه‌ی داده‌ها یک‌جا)، `GET/PUT /api/settings` |
| متریال | `GET/POST /api/materials` • `PUT/DELETE /api/materials/{id}` • `POST /api/materials/{id}/toggle` • `POST /api/materials/bulk` • `GET /api/price-history` • `GET /api/materials/export` (xlsx) |
| سبک | `GET/POST /api/styles` • `PUT/DELETE /api/styles/{id}` • `POST /api/styles/{id}/duplicate` |
| پروژه | `GET/POST /api/projects` • `GET/PUT/DELETE /api/projects/{id}` • `POST /api/projects/{id}/duplicate` • `POST /api/calc` (محاسبه‌ی زنده با موتور واقعی) |
| فاکتور | `POST /api/invoice/preview` (داده + HTML آماده‌ی چاپ) • `POST /api/invoice/save` • `POST /api/invoice/pdf` • `POST /api/invoice/xlsx` • `GET/DELETE /api/invoices/{id}` • `GET /api/invoices/{id}/pdf` |
| پشتیبان | `GET/POST/DELETE /api/backups` • `POST /api/backups/restore` • `GET /api/backups/export` • `POST /api/backups/import` |

## قابلیت‌های رابط کاربری

- **۶ صفحه‌ی کامل**: داشبورد، پروژه‌ها، متریال و خدمات، سبک‌ها، فاکتور، تنظیمات
- **ویرایشگر پروژه‌ی ترکیبی**: چند بخش (سبک)، یونیت‌ها با جزئیات متریال بازشونده،
  در/کشو به‌ازای هر یونیت، درنما (ریز/کلی)، اضافات، خدمات با مبنای خودکار
- **محاسبه‌ی زنده**: هر تغییر → `POST /api/calc` → موتور واقعی پایتون (در حالت
  نمایشی، آینه‌ی JS همان موتور)
- **فاکتور**: پیش‌نمایش با `render_html` خود برنامه (iframe)، سطح گروه‌بندی/ریز/خلاصه،
  پنهان‌سازی ردیف، نسخه‌ی داخلی (با هزینه) / مشتری، چاپ، PDF، اکسل، بایگانی
- **تجربه‌ی کاربری سطح تجاری**: اسپلش برنددار راه‌اندازی، اسکلتون/اسپینر روی
  عملیات ناهمزمان، توست با نوار پیشرفت و دکمه‌ی بستن، شمارنده‌ی متحرک آمار،
  مرتب‌سازی جدول‌ها با کلیک روی سرستون، سرستون چسبان، ساعت و تاریخ شمسی در نوار
  بالا، بنر هشدار حالت نمایشی، پایش خودکار اتصال
- **دسترس‌پذیری**: فوکوس‌تراپ مودال‌ها، `aria-*`، پشتیبانی `prefers-reduced-motion`،
  کنتراست مناسب در هر دو پوسته
- **پوسته‌ی روشن/تاریک**، اندازه‌ی قلم، اعداد فارسی/لاتین، واحد پول و مقیاس (ریال/تومان)
- **جست‌وجوی سراسری** (`/`)، میان‌بر صفحه‌ها (`Alt+1..6`)، ذخیره با `Ctrl+S`،
  هشدار تغییرات ذخیره‌نشده
- **واکنش‌گرا**: نوار کناری کشویی در موبایل، چیدمان تطبیقی جدول‌ها
- **PWA**: مانیفست + آیکون‌ها برای نصب‌پذیری از مرورگر
