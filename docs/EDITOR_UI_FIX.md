> بازبینیِ کاملِ رابطِ ویرایشگر پروژه (وب‌یوآی) پس از کامیتِ `8071d01`
> («Add a modern UI layer…») که بدنه‌ی `webui/index.html` را حذف کرده بود.
> موتور محاسبه، API و منطقِ برنامه **دست‌نخورده** است؛ همه‌ی تغییرات در
> `webui/index.html`، `webui/css/styles.css`، `webui/js/ui.js`، `webui/js/ui-modal.js`
> و یک بررسیِ آزمودنی (`tests/ui_dom_check.js`) است.

## ۳) مکانیزمِ جدیدِ `--tb-h` / `--addbar-h`

تابعِ `syncStickyOffsets()` در `ui.js` ارتفاعِ زنده‌ی نوارِ جمع و نوارِ «افزودنِ» چسبانِ تبِ فعال را
در دو متغیرِ CSS روی `<html>` می‌نویسد. این تابع با `ResizeObserver` روی `#totalBar`،
رویدادِ `resize`، باز/بسته‌شدنِ کشوی مالی، باز/بسته‌شدنِ ویرایشگر و جابه‌جایی تب صدا می‌شود.
نتیجه: هیچ لایه‌ی چسبانی زیر/روی لایه‌ی چسبانِ دیگر نمی‌افتد — در هر ارتفاعِ صفحه و هر وضعیتِ کشو.

## ۴) آزمودنی‌ها

  به رفتارِ مستندِ «کشو بسته‌ی پیش‌فرض + باز/بسته‌شدن با کلیک» به‌روز شد.
- نتیجه‌ی اجرا پس از تعمیر:
  - `ui_dom_check` ✅ · `ui_features_check` ✅ · `ui_modal_guard_check` (۱۰۵) ✅ · `ui_connected_check` ✅
  - `ux_flow_test` (۲۶) ✅ · `ux_doors_test` (۳۰) ✅ · `workshop_check` (۱۰۵) ✅
  - `parity_check` و `parity_edge_check` (برابری JS/پایتون) ✅
