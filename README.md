# 🗄 کبیر — نرم‌افزار محاسبه‌ی قیمت تمام‌شده و صدور فاکتور کابینت

**نسخه‌ی ۲٫۱ — کاملاً تحت وب.** کبیر یک نرم‌افزار **محلی و بدون اینترنت** برای کارگاه‌ها
و فروشگاه‌های کابینت‌سازی است: ابتدا **هزینه‌ی واقعی** مواد و خدمات محاسبه می‌شود،
سپس سود، نصب، تخفیف و مالیات اعمال و در نهایت **فاکتور حرفه‌ای (چاپ/PDF/اکسل)**
صادر می‌شود. تمام رابط کاربری تحت وب است (مرورگر) و داده‌ها در یک پایگاه‌داده‌ی
SQLite روی سیستم خودتان نگهداری می‌شوند.

## ۱) نصب و اجرا

### پیش‌نیاز
- پایتون **۳٫۱۰ یا بالاتر** — [python.org](https://www.python.org/downloads/)
  (در ویندوز تیک *Add Python to PATH* را بزنید)

### ویندوز
```bat
install.bat      :: نصب وابستگی‌ها
run.bat          :: اجرای کبیر (مرورگر خودکار باز می‌شود)
```

### لینوکس / مک
```bash
./install.sh     # نصب وابستگی‌ها
./run.sh         # اجرای کبیر (مرورگر خودکار باز می‌شود)
```

### دستی
```bash
pip install -r requirements.txt
python main.py
```

> نکته: هسته‌ی نرم‌افزار (سرویس وب + رابط کاربری) فقط با **کتابخانه‌ی استاندارد
> پایتون** کار می‌کند؛ وابستگی‌های `requirements.txt` برای خروجی **PDF و اکسل** لازم‌اند.

### گزینه‌های خط فرمان
```bash
python main.py --port 9000      # پورت دلخواه (پیش‌فرض 8080)
python main.py --no-browser     # بدون باز کردن مرورگر
python main.py --host 0.0.0.0   # دسترسی از شبکه‌ی محلی (مثلاً تبلت در کارگاه)
python main.py --version        # نمایش نسخه
```

اگر پورت ۸۰۸۰ اشغال باشد، کبیر به‌صورت خودکار پورت آزاد بعدی را انتخاب و اعلام می‌کند.
ویندوز: `run.bat` — لینوکس/مک: `./run.sh`

> در اولین اجرا، فونت وزیرمتن از اینترنت دانلود و در پوشه‌ی برنامه ذخیره می‌شود
> (اگر اینترنت نبود، از فونت‌های فارسی نصب‌شده روی سیستم استفاده می‌شود).

### نسخه‌ی تک‌فایلی (بدون سرور)
فایل `webui/kabir-ui-standalone.html` را مستقیم در مرورگر باز کنید: رابط با
داده‌های نمونه و موتور محاسبه‌ی جاوااسکریپتی (آینه‌ی دقیق موتور پایتون) کار می‌کند
و تغییرات در حافظه‌ی مرورگر می‌ماند — مناسب دمو و آشنایی اولیه.

## ۲) راهنمای سریع استفاده

| مرحله | صفحه | کار |
|---|---|---|
| ۱ | **متریال و خدمات** | قیمت روز ورق، فیبر، در، تاج، زیرچراغ، پاخور، صفحه، نوار، لولا، گازور، خار، دستگیره، پایه، ریل و خدمات را وارد کنید. «تغییر دسته‌جمعی قیمت» برای به‌روزرسانی سریع نرخ بازار است و همه‌ی تغییرات در «تاریخچه قیمت» ثبت می‌شوند. |
| ۲ | **سبک‌ها** | ترکیب متریال پرکاربرد خود را یک‌بار ذخیره کنید (تا ۲۰ سبک) و در هر پروژه با یک کلیک فراخوانی کنید. |
| ۳ | **پروژه‌ها** | پروژه بسازید؛ برای هر *بخش* (سبک) یونیت‌ها را با ابعاد دقیق (طول/ارتفاع/عمق/تعداد/طبقات) وارد کنید؛ درها و کشوها را با مدل، لولا، جک، دستگیره، مونتاژ و بسته‌بندی تعریف کنید؛ درنما را ریز یا کلی وارد کنید؛ اضافات (نورپردازی و…) و خدمات بخش را اضافه کنید. |
| ۴ | **پروژه‌ها → نوار پایین** | روش سود (مارکاپ/مارجین)، نصب (ثابت/متری/درصدی)، تخفیف و مالیات را تنظیم کنید؛ «محاسبه‌ی دقیق» ریز هزینه‌ها را نشان می‌دهد. |
| ۵ | **فاکتور** | سطح نمایش (گروه‌بندی/ریز/خلاصه) و ردیف‌های قابل‌نمایش را انتخاب کنید، سپس چاپ (مرورگر)، PDF یا اکسل بگیرید. |

### میان‌برهای صفحه‌کلید
| میان‌بر | کار |
|---|---|
| `/` | جست‌وجوی سراسری |
| `Alt+۱..۶` | رفتن به صفحه‌ها |
| `Ctrl+S` | ذخیره‌ی پروژه‌ی در حال ویرایش |
| `Esc` | بستن مودال/جست‌وجو/منو |
| کلیک روی سرستون‌ها | مرتب‌سازی جدول‌ها |

### فرمول‌های کلیدی محاسبه
- **مساحت بدنه‌ی هر یونیت** = ۲×(عمق×ارتفاع) + ۲×(عرض×عمق) + طبقات داخلی + فیبر پشت
  (قابل مشاهده در «جزئیات» هر یونیت)
- **تعداد ورق مصرفی** = سقف( مساحت × (۱ + پرت٪) ÷ مساحت ورق )
- **نوار PVC بدنه** = مساحت بدنه × ضریب نوار (پیش‌فرض ۲٫۲) + پرت نوار
- **نوار PVC در** = محیط در × تعداد لنگه × ضریب
- **مارکاپ**: فروش = هزینه × (۱ + درصد/۱۰۰)  |  **مارجین**: فروش = هزینه ÷ (۱ − درصد/۱۰۰)
- **نصب متری** = نرخ × مجموع متر طول یونیت‌های زمینی/کمد

├── requirements.txt            وابستگی‌های خروجی PDF/اکسل
├── webui/                      رابط کاربری وب (HTML/CSS/JS — بدون فریم‌ورک)
│   ├── index.html              پوسته‌ی اصلی و هر ۶ صفحه
│   ├── css/styles.css          پوسته روشن/تاریک، RTL، واکنش‌گرا، چاپ
│   ├── js/data.js              داده‌ها + لایه‌ی اتصال به API

│   ├── assets/                 فاوآیکون، آیکون‌ها و فونت وزیرمتن
│   └── build_standalone.py     ساخت نسخه‌ی تک‌فایلی (kabir-ui-standalone.html)
├── assets/fonts/               فونت وزیرمتن (برای خروجی PDF)
├── kabir/
│   ├── config.py               مسیرها و تنظیمات پیش‌فرض (چندسکویی)
│   ├── core/
│   │   ├── persian.py          اعداد فارسی، تاریخ شمسی، عدد به حروف

│   │   ├── costing.py          ★ موتور محاسبه‌ی قیمت تمام‌شده

│   │   ├── invoice_pdf.py      خروجی PDF راست‌به‌چپ با ReportLab
│   │   └── exporters.py        خروجی‌های Excel (ریز، برش‌کاری، فاکتور)
│   ├── data/
│   │   ├── db.py               لایه‌ی SQLite + تنظیمات
│   │   ├── dao.py              CRUD متریال/سبک/پروژه/فاکتور + تاریخچه قیمت
│   │   ├── seed.py             داده‌های نمونه‌ی صنعت کابینت
│   │   └── backup.py           پشتیبان‌گیری/بازیابی/ورود و خروج JSON
│   └── web/
│       └── server.py           ★ سرویس‌دهنده‌ی وب + API (کتابخانه‌ی استاندارد)
├── tests/                      تست واحد موتور + تست دود سرور + برابری JS/پایتون
└── samples/                    نمونه خروجی‌های فاکتور (PDF/HTML/XLSX)

### تست‌ها
```bash
pip install pytest
pytest tests -v                                  # تست‌های واحد + دود سرور
python tests/parity_export.py && node tests/parity_check.js   # برابری موتور JS و پایتون
```

### نصب به‌صورت بسته‌ی پایتون (اختیاری)
```bash
pip install .
kabir            # دستور کبیر در ترمینال
```

## ۴) محل ذخیره‌ی داده‌ها

| سیستم‌عامل | مسیر |
|---|---|
| ویندوز | `%APPDATA%\KabirCabinet` |
| لینوکس | `~/.local/share/KabirCabinet` |

شامل: `kabir.db` (پایگاه‌داده)، `backups/` (پشتیبان‌ها)، `exports/` (خروجی‌ها)، `fonts/`.

> متغیر محیطی `KABIR_DATA_DIR` مسیر داده را جایگزین می‌کند (مناسب نسخه‌ی قابل‌حمل).

## ۵) نکته‌ها

- قیمت‌های نمونه‌ی اولیه فقط برای راه‌اندازی سریع‌اند؛ حتماً نرخ‌های خودتان را وارد کنید.
- «پروژه‌ی ترکیبی»: در یک پروژه چند *بخش* بسازید و برای هر بخش سبک متفاوت انتخاب کنید؛
  هزینه‌ها خودکار جمع می‌شوند. «مبلغ ثابت اضافه» برای تفاوت قیمت نوع درِ بخش‌هاست.
- فاکتور دو نسخه‌ی داخلی/مشتری دارد: با تیک «نمایش ستون هزینه‌ی تمام‌شده» می‌توانید
  نسخه‌ی حاوی هزینه را فقط برای خودتان نگه دارید.
- برای چاپ: دکمه‌ی «چاپ» سند را آماده‌ی چاپ مرورگر می‌کند (Ctrl+P).
- نشانگر بالای صفحه وضعیت اتصال را نشان می‌دهد؛ اگر سرور قطع شود، رابط به‌صورت
  خودکار «حالت نمایشی» را فعال و برای اتصال مجدد تلاش می‌کند.
